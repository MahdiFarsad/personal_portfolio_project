# وب‌سایت پورتفولیو شخصی

یک وب‌سایت پورتفولیو شخصی که با **Next.js** (به‌صورت استاتیک اکسپورت) در بخش فرانت‌اند و **PHP + MySQL** در بخش بک‌اند ساخته شده است — شامل نمایش پروژه‌ها در زمینه‌های یادگیری ماشین، یادگیری عمیق، علم داده، بینایی کامپیوتر، ژنتیک و یادگیری ماشین زیست‌پزشکی، و همچنین پروژه‌های فول‌استک.

**آدرس سایت:** [mahdifarsad.com](https://mahdifarsad.com)

---

## امکانات

- **صفحه اصلی / درباره من** — معرفی، لینک‌های ارتباطی، دانلود رزومه
- **پروژه‌ها** — لیست و صفحه جزئیات پروژه‌ها که مستقیماً از دیتابیس خوانده می‌شوند، قابل فیلتر بر اساس دسته‌بندی و وضعیت
- **پروژه‌های پیش‌رو** — نمایش پروژه‌هایی که در حال حاضر در دست انجام هستند
- **سوابق کاری** — نمایش بصری (تایم‌لاین) از سوابق شغلی
- **تحصیلات و پژوهش** — سوابق تحصیلی و پروژه‌های پژوهشی/دانشگاهی
- **بلاگ** — مطالب وبلاگ که از دیتابیس خوانده می‌شوند، همراه با صفحه لیست و جزئیات
- **تماس با من** — فرم درخواست/تماس کاربردی همراه با محافظت در برابر اسپم، ذخیره در دیتابیس و ارسال ایمیل هنگام ثبت
- **پنل مدیریت** — یک داشبورد محافظت‌شده با رمز عبور برای افزودن، ویرایش و حذف پروژه‌ها و مطالب بلاگ، و مشاهده/مدیریت پیام‌های فرم تماس — همه بدون نیاز به دست‌زدن به کد

## تکنولوژی‌های استفاده‌شده

**فرانت‌اند**
- [Next.js](https://nextjs.org/) (App Router، به‌صورت استاتیک اکسپورت)
- [Tailwind CSS v4](https://tailwindcss.com/)
- استفاده از `fetch` ساده برای دریافت داده در سمت کاربر (بدون نیاز به کتابخانه مدیریت state اضافه)

**بک‌اند**
- PHP (بدون فریم‌ورک) به همراه PDO برای ارتباط با دیتابیس
- MySQL

**دلیل انتخاب این تکنولوژی‌ها:** این سایت روی یک هاست اشتراکی/ابری میزبانی می‌شود که فقط از اجرای PHP پشتیبانی می‌کند (بدون امکان اجرای Node.js یا Python). به همین دلیل، فرانت‌اند به‌صورت کاملاً استاتیک (فایل‌های ساده HTML/CSS/JS) ساخته شده و در کنار یک API سبک PHP که مسئول داده‌های پویا و ثبت فرم‌ها است، سرو می‌شود.

## ساختار پروژه

```
portfolio/
├── database/
│   └── schema.sql          # ساختار کامل دیتابیس MySQL
├── backend/
│   ├── includes/           # اتصال مشترک به دیتابیس، تنظیمات، توابع احراز هویت
│   ├── api/                # اندپوینت‌های PHP (پروژه‌ها، مطالب بلاگ، فرم تماس)
│   └── admin/               # پنل مدیریت محتوا با محافظت رمز عبور
└── frontend/
    └── src/
        ├── app/             # صفحات Next.js (App Router)
        ├── data/            # محتوای ثابت (سوابق کاری، تحصیلات)
        └── app/components/  # کامپوننت‌های مشترک رابط کاربری
```

## اجرا به‌صورت محلی (Local)

**پیش‌نیازها:** Node.js (نسخه LTS)، یک محیط محلی PHP + MySQL (مانند [Laragon](https://laragon.org/)، XAMPP یا MAMP)

۱. کلون کردن ریپازیتوری:
   ```bash
   git clone https://github.com/MahdiFarsad/personal_portfolio_project.git
   ```
۲. فایل `database/schema.sql` را از طریق phpMyAdmin در یک دیتابیس MySQL محلی ایمپورت کنید.
۳. فایل `backend/includes/config.example.php` را کپی کرده و به نام `backend/includes/config.php` ذخیره کنید، سپس اطلاعات دیتابیس محلی خود را در آن وارد کنید.
۴. پوشه `backend/` را از طریق محیط Apache/PHP محلی خود سرو کنید.
۵. نصب و اجرای فرانت‌اند:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
۶. به آدرس `http://localhost:3000` مراجعه کنید.

## دیپلوی (انتشار روی هاست)

فرانت‌اند به‌صورت استاتیک اکسپورت می‌شود (`npm run build`، با تنظیم `output: 'export'` در فایل `next.config.mjs`) و به همراه بک‌اند PHP روی هر هاست استاندارد Apache/PHP/MySQL آپلود می‌شود — بدون نیاز به اجرای Node.js یا Python روی سرور.
